Security and privacy

Built to need as little of your data as possible.

We read operational data such as tickets and conversations: only what the analysis needs, where your data lives when required, and never to judge individuals.

Data minimization

  • Read-only connectors, limited to the fields we need. We never write back.
  • Timestamps, categories, teams and outcomes. Free text is read to type work, then dropped.
  • Names and user IDs are replaced with keyed hashes before anything is stored; raw uploads are not kept.
  • Team-level results only, with a minimum group size.

People and regulation

  • Evaluates AI programs, not people: no scoring, ranking or monitoring of individual workers.
  • A standard description of the team-level design for works council consultations.
  • Data processing agreement, an EU hosting option and configurable retention.
  • Any AI we use runs on endpoints you approve. Your data never trains models.

Security program

  • TLS in transit, encrypted storage, and secrets encrypted in the database.
  • Single sign-on, role-based access and a complete audit log.
  • Strict browser security headers; no third-party scripts or trackers.
  • Penetration testing before general availability; SOC 2 Type II, ISO 27001 and ISO 42001 planned, in that order.

To report a vulnerability, use the private reporting channel on our GitHub repository.
