About

One person, an open method, and no vendor money.

Probative Labs is a one-person company today. Everything it claims can be checked: the code is open, the validation is published, and the independence rules are public.

Founder

AI vendors report their own results, and the people who pay for the AI have no independent way to check them. I built Probative Labs to give them one: an open method anyone can rerun, and a check that runs on their own data. I write the engine and run every check myself.
