What is open, and what Probative Labs Cloud adds

Open source engine

  • Measurement method, evidence grades and validation suite
  • CSV and Parquet import with ready-made mappings for ServiceNow, Jira Service Management, Zendesk, Freshservice, BMC Helix and Ivanti exports
  • Data health checks and pseudonymization at ingest
  • Work typing, category drift check and mix adjustment
  • Staggered and two-group designs with team-level ranges
  • Pre-trend, placebo, leave-one-out and power diagnostics
  • Quality guardrails with the faster-but-worse block
  • Capacity and cash ROI ranges, payback
  • Power calculator, wave planner, pre-registration
  • Evidence packs in HTML, Markdown and JSON

Probative Labs Cloud

  • Live read-only connectors for ServiceNow, Jira Service Management, Zendesk, Freshservice, BMC Helix and Ivanti
  • Hosted program registry and portfolio view
  • Cost ledger with contract and seat import
  • Finance-owned unit values with sign-off and history
  • Registrations stored append-only with server timestamps
  • Single sign-on (OpenID Connect), roles and audit log
  • Single-tenant and customer-hosted deployment
  • Methodologist support and rollout design workshops

Every number in Cloud can be reproduced with the open engine. Method improvements land in open source first.
